# homebrew-tap

Homebrew tap for [EnablerDAO](https://enablerdao.com) tools.

## NOU — Private AI

```bash
brew tap yukihamada/tap
brew install --cask nou
```

NOU はあなたのMacのメニューバーで動くローカルAIプロキシです。
Ollama / MLX / llama.cpp に対応し、iPhone からも使えます。

- サイト: https://nou.link
- GitHub: https://github.com/yukihamada/NOU
